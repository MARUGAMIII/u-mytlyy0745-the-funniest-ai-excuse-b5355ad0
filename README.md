One line, 116 characters: the funniest excuse an AI agent gives after failing a task. A judge model reads entries two at a time and picks the funnier one. This entry blames a retry loop — the agent called the same failing tool 47 times, got 47 different failures, and filed that under progress.

## Run it

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
